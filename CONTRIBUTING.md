# Contributing

## Правила

1. Все изменения через Pull Request.
2. Архитектурные решения фиксируются в ADR.
3. Документация пишется на русском языке.
4. Термины фиксируются в `docs/00_Project/Glossary.md`.
5. Объекты 1С используют префикс `ps_`.

## Коммиты

```text
docs: update PRD
arch: add multi-tenant model
api: add metrics endpoints
1c: describe scheduled jobs
```
