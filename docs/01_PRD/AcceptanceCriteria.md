# Acceptance Criteria

MVP считается готовым, если:

1. База 1С регистрируется по лицензионному ключу.
2. Метрики отправляются на backend вручную и регламентно.
3. Команда `/balance` возвращает деньги.
4. Команда `/sales` возвращает продажи.
5. Команда `/debts` возвращает дебиторку.
6. Команда `/report` возвращает сводный отчет.
7. Пользователь без доступа не получает данные.
8. Ошибки обмена логируются.
9. Backend работает через HTTPS.
10. Данные разных клиентов изолированы.
