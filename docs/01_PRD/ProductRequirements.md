# Product Requirements Document

## Назначение

Документ описывает требования к платформе PSGroup Business AI Platform и первому модулю ps_DirectorBot.

## Пользователи

- Собственник;
- Директор;
- Финансовый директор;
- Руководитель продаж;
- Администратор PSGroup;
- Специалист поддержки.

## MVP-функции

- регистрация клиента;
- выдача лицензионного ключа;
- регистрация базы 1С;
- отправка агрегированных метрик;
- команды `/balance`, `/sales`, `/debts`, `/report`;
- роли пользователей;
- хранение логов;
- базовое лицензирование.

## Ограничения MVP

- нет прямого изменения документов 1С;
- нет записи в 1С через Telegram;
- нет хранения полных документов;
- нет AI-действий;
- только read-only аналитика.
