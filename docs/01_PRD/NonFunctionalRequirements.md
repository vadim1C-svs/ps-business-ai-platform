# Non-Functional Requirements

## Надежность
- Ошибка обмена не должна блокировать работу 1С.
- Все ошибки должны логироваться.

## Производительность
- Ответ Telegram-команды: до 3 секунд при наличии свежих метрик.
- Отправка пакета метрик из 1С: до 10 секунд.

## Безопасность
- Только HTTPS.
- Подпись запросов.
- Проверка nonce.
- Изоляция клиентов.
- Хранение только агрегированных данных.

## Совместимость
- 1С:Предприятие 8.3.
- УНФ 3.0.
- УТ.
- Розница.
- Бухгалтерия для Казахстана.
