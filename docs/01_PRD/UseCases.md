# Use Cases

## UC-001. Подключение базы

1. Пользователь открывает форму настроек.
2. Вводит адрес сервера и ключ.
3. Нажимает "Проверить подключение".
4. Расширение отправляет запрос регистрации.
5. Backend проверяет ключ.
6. Backend создает запись базы.
7. Расширение сохраняет database_id.

## UC-002. Получение отчета

1. Пользователь отправляет `/report`.
2. Бот определяет пользователя.
3. Backend проверяет права.
4. Backend получает свежие метрики.
5. Бот формирует текст.
6. Telegram отправляет сообщение.
