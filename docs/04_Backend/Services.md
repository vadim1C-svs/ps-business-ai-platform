# Backend Services

## AuthService
Проверяет API key, license key, Telegram ChatID, подпись запроса, nonce.

## MetricsService
Прием, валидация, сохранение и выдача метрик.

## LicenseService
Проверка тарифа, ограничений и срока действия лицензии.

## NotificationService
Уведомления Telegram/WhatsApp/Admin.

## AIService
Классификация намерений, выбор tool, генерация ответа.
