# Backend FastAPI

## Назначение

Backend принимает метрики из 1С, хранит агрегированные данные, обслуживает Telegram Bot, управляет лицензиями и подготавливает данные для AI.

## Стек

- Python 3.12+;
- FastAPI;
- Pydantic;
- SQLAlchemy 2;
- Alembic;
- PostgreSQL;
- Redis;
- Celery/RQ;
- Uvicorn/Gunicorn;
- Nginx.
