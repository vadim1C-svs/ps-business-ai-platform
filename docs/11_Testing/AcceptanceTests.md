# Acceptance Tests

## AT-001. Подключение базы
Дано: активная лицензия. Когда пользователь вводит ключ в 1С, база регистрируется на backend.

## AT-002. Получение денег
Дано: есть свежие метрики. Когда пользователь отправляет `/balance`, бот возвращает остатки денег.

## AT-003. Нет доступа
Дано: Telegram ChatID не привязан. Когда пользователь отправляет `/report`, бот возвращает отказ доступа.
