# Scheduled Jobs

## Регламентное задание

`ps_РегламентнаяОтправкаМетрикBusinessAI`

Периодичность: 5, 15, 30, 60 минут. По умолчанию 15 минут.

## Алгоритм

1. Проверить, включен ли обмен.
2. Проверить настройки.
3. Собрать метрики.
4. Сформировать JSON.
5. Подписать пакет.
6. Отправить на backend.
7. Записать результат.
8. Обработать очередь неотправленных пакетов.
