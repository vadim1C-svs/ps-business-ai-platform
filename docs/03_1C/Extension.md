# 1C Extension Architecture

## Название расширения
`ps_BusinessAIAgent`

## Принципы

1. Не изменять типовую конфигурацию.
2. Не хранить лишние данные.
3. Не блокировать проведение документов.
4. Все длительные операции выполнять фоново.
5. Ошибки обмена не должны мешать работе пользователей.
6. Все объекты имеют префикс `ps_`.

## Формы

- `ps_ФормаНастроекBusinessAI`;
- `ps_ФормаПроверкиПодключения`;
- `ps_ФормаЛогаОбмена`;
- `ps_ФормаДиагностикиМетрик`.

- `ps_НастройкиBusinessAI`;
