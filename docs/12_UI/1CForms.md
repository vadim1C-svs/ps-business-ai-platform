# 1C Forms

## Форма настроек

Поля: адрес сервера, лицензионный ключ, идентификатор базы, организация, период обмена, использовать регламентное задание, дата последнего успешного обмена, последний текст ошибки.

Команды: проверить подключение, отправить метрики сейчас, открыть лог, открыть инструкцию, очистить настройки.
