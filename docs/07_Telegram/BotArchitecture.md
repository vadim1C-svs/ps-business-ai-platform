# Telegram Bot Architecture

## Назначение

Telegram Bot является первым пользовательским интерфейсом платформы.

## Задачи

- принять команду;
- определить пользователя;
- проверить права;
- получить данные из backend;
- сформировать сообщение;
- отправить ответ.

## Рекомендуемая библиотека
`aiogram 3.x`
